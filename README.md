# Linux System Administration & Automation Toolkit

## Overview

A practical Linux administration project built with Ubuntu and Bash scripting.

## Features

- System information reporting
- CPU and memory process monitoring
- Disk usage alerts
- Network troubleshooting
- User auditing
- File permission auditing
- Log analysis
- Backup creation and verification
- System health reports
- Cron scheduling
- Nginx website deployment

## Technologies

- Ubuntu Linux
- Bash
- Git and GitHub
- Nginx
- Cron
- Linux networking utilities

## Project Structure

- scripts/: Linux automation scripts
- reports/: Generated reports
- backups/: Local backup archives
- docs/: Installation and troubleshooting guides
- web/: Demo website
- tests/: Test files

## Run

Make scripts executable:

    chmod +x scripts/*.sh

Display system information:

    ./scripts/system_info.sh

Generate disk report:

    ./scripts/disk_report.sh

Generate process report:

    ./scripts/process_report.sh

Check network connectivity:

    ./scripts/network_check.sh

Generate health report:

    ./scripts/health_check.sh

## Environment

Developed for Ubuntu Linux and tested in WSL where supported.

Some service-management features depend on the environment.
